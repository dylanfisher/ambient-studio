Model test

A model test checks how well the local model follows your briefs, without making any audio. For each brief you tick, it asks the model for the number of candidates you set, checks whether each answer follows the format and the brief's rules, gives a failed answer one chance to fix it, and reports how often that worked and how long each request took. Run one after changing a brief's rules, or when sessions give many rejected candidates. To get something to listen to, start a session from a brief instead. With the revision test ticked it also renders each answer's excerpt, and sends every one that misses one of the brief's feature ranges back to the model twice: once with its measurements and once without, to find out whether hearing the measurements helps.
