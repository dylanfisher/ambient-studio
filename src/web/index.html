How the studio works

  1. Write a brief. Give it a name, describe the music in a few sentences, and set any rules every candidate must follow, such as a key or a length. Write a new brief
  2. Start a session. On the brief's page, press Start a session. The studio asks the local model for candidates and renders a 25-second excerpt of each by itself. This takes about a minute or two per candidate. Choose a brief
  3. Listen and rate. On the session page, play each excerpt and press thumbs up or down. You can also say a candidate should be brighter, denser and so on, or compare two side by side.
  4. Keep the ones you like. Press Keep as sketch on a candidate to save it, with a note and tags. The brief's page lists every rating and sketch.
  5. Check the model now and then. A model test asks the model for many candidates without making audio, and reports how often it followed the brief. Open the model test
